# YapStack Releases

Public release artifacts for [YapStack](https://yapstack-voice-magic.lovable.app/).

Source code is not hosted here — this repository only publishes signed macOS installers.

## Install

### Homebrew (recommended)

```bash
brew install yapstackai/tap/yapstack
```

Upgrade:

```bash
brew update && brew upgrade --cask yapstack
```

### Manual download

Download the latest DMG from [Releases](https://github.com/yapstackai/yapstack-releases/releases), open it, and drag **YapStack.app** to **Applications**.

## Requirements

- macOS on Apple Silicon (arm64)
